# 🎯 CSS Flexbox Parent Properties

A simple and beginner-friendly project that demonstrates the most commonly used **CSS Flexbox Parent Properties**. This project helps you understand how different Flexbox properties align and distribute items inside a flex container.

---

## ✨ Features

- 📌 Demonstrates `justify-content`
- 📌 Demonstrates `align-items`
- 📌 Demonstrates `align-content`
- 🎨 Clean and easy-to-understand UI
- 📚 Beginner-friendly examples
- 💻 Pure HTML & CSS
- 📱 Responsive Flexbox layout

---

## 🛠️ Technologies Used

- 🌐 HTML5
- 🎨 CSS3 (Flexbox)

---

# 📖 Flexbox Properties Covered

## 1️⃣ justify-content

Controls the alignment of flex items along the **Main Axis**.

### Examples

- ✅ `flex-start`
- ✅ `flex-end`
- ✅ `center`
- ✅ `space-between`
- ✅ `space-around`
- ✅ `space-evenly`

---

## 2️⃣ align-items

Controls the alignment of flex items along the **Cross Axis**.

### Examples

- ✅ `flex-start`
- ✅ `flex-end`
- ✅ `center`
- ✅ `stretch`

---

## 3️⃣ align-content

Controls the spacing between multiple rows of flex items when wrapping is enabled.

### Examples

- ✅ `space-between`
- ✅ `space-around`
- ✅ `space-evenly`
