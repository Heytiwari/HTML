## 📖 Topics Covered

### 1. Display: Flex

Flexbox is short for the **Flexible Box Layout Module**. It is a layout method for arranging items in rows or columns. Flexbox makes it easier to create flexible and responsive layouts without using floats or positioning.

---

### 2. Flex Wrap

The `flex-wrap` property specifies whether flex items should wrap when there is not enough space on a single line.

Available values:

- `nowrap`
- `wrap`
- `wrap-reverse`

Examples included:

- Flex Wrap: `nowrap`
- Flex Wrap: `wrap`
- Flex Wrap: `wrap-reverse`

---

### 3. Flex Direction

The `flex-direction` property specifies the direction of the flex items inside the flex container.

Available values:

- `row`
- `column`
- `row-reverse`
- `column-reverse`

Examples included:

- Flex Direction: `row`
- Flex Direction: `column`
